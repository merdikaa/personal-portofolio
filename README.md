### 🥁 3. Drum Bass – Virtual Drum With Keyboard

**Deskripsi:**  
Aplikasi interaktif berbasis web di mana pengguna dapat memainkan berbagai suara drum menggunakan tombol keyboard.  
Dibangun dengan **HTML, CSS, dan JavaScript murni**, proyek ini melatih kemampuan event handling dan manipulasi DOM.

**🔧 Teknologi:**  
`HTML5`, `CSS3`, `JavaScript (Vanilla)`

**✨ Fitur:**

- Interaksi keyboard (`W`, `A`, `S`, `D`, `J`, `K`, `L`)
- Animasi efek visual saat tombol ditekan
- Suara drum real-time
- Desain responsif dan clean

📂 [Lihat Proyek Drum Berbasis Web](https://github.com/merdikaa/drum-page)
